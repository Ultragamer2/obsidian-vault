# Sync - Free with Git

Paid Obsidian Sync not needed. Vault is just markdown + git, free and syncs with your computer.

## First time on your computer
```
git clone <your-repo-url> "Obsidian Vault"
```

## Daily use
```
git pull
git add .
git commit -m "vault update"
git push
```
